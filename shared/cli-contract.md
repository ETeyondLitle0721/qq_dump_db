# CLI 契约（规范 v1）

## 1. 命令形式

```text
qq_dump_db --qq <QQ号> [--pid <PID>] [--db-dir <目录>]
           [--output <JSON路径>] [--output-dir <目录>]
           [--lang <auto|zh-CN|en-US|ja-JP>] [--no-wait]
           [--help] [--version]

python dump_qq_key_auto.py --qq <QQ号> [同上参数]
```

Python 包化后，`python -m qq_dump_db` 应继续接受相同参数。参数名称、取值和含义在两种实现中保持一致。

## 2. 参数定义

| 参数 | 必需 | 默认值 | 规范语义 |
|---|---:|---|---|
| `--qq <QQ号>` | 是 | 无 | 目标账号目录名。按字符串处理，不转成整数；当前版本只接受非空数字字符串。 |
| `--pid <PID>` | 否 | 自动映射 | 显式指定用于扫描的进程 PID，是诊断覆盖项；指定后不再由自动映射替换。PID 必须是大于 0 的十进制整数。 |
| `--db-dir <目录>` | 否 | 自动发现 | 指定账号数据库目录，必须存在。它覆盖自动发现的账号数据库目录；按当前行为，不从该目录额外推导全局数据库目录。 |
| `-o, --output <路径>` | 否 | `key_map.json` | 密钥映射 JSON 文件路径。相对路径以最终输出目录为基准；绝对路径按原样使用。 |
| `--output-dir <目录>` | 否 | `./output/<QQ号>` | 全部默认输出文件的根目录。相对路径以进程当前工作目录为基准；目录不存在时创建。 |
| `--lang <语言>` | 否 | `auto` | 控制用户可见文案语言。允许 `auto`、`zh-CN`、`en-US`、`ja-JP`。不改变 JSON 字段、错误码或文件名。 |
| `--no-wait` | 否 | 关闭 | 跳过等待 QQ 退出和 WAL 刷新提示，直接重新读取数据库。使用此选项时应打印 WAL 可能尚未完整 checkpoint 的警告。 |
| `-h, --help` | 否 | — | 显示帮助并以退出码 `0` 结束，不扫描进程。 |
| `--version` | 否 | — | 显示程序版本并以退出码 `0` 结束，不扫描进程。 |

未知参数、缺失参数值、非法 PID、非法 QQ 号或不支持的语言值均属于 CLI 用法错误，退出码为 `2`。

## 3. 默认输出路径

未显式指定 `--output-dir` 时，输出根目录为：

```text
<当前工作目录>/output/<QQ号>/
```

默认密钥文件：

```text
<输出根目录>/key_map.json
```

解密后的数据库文件也放在输出根目录中。保持现有扁平文件布局；如果不同源数据库映射到同一个目标文件名，必须报告冲突并禁止静默覆盖。

`--output-dir` 仅改变输出根目录，不改变输入数据库目录。`--output` 仅改变密钥 JSON 文件的位置，不改变解密数据库的输出位置。

## 4. 路径规则

- 路径按 Windows 文件系统语义处理；支持包含空格和非 ASCII 字符的路径。
- `--output-dir` 的相对路径相对于进程当前工作目录解析，不相对于脚本文件位置。
- `--output` 的相对路径相对于最终输出根目录解析；绝对路径不再拼接输出根目录。
- 输出目录及 JSON 文件的父目录按需创建。
- 文件写入应采用同目录临时文件 + 完成后原子替换的方式，避免失败时留下半截 JSON。
- 输入路径不得因输出路径设置而被覆盖；若输出路径与待处理输入数据库路径相同，应拒绝执行。

## 5. 语言选择优先级

语言解析顺序：

1. `--lang zh-CN|en-US|ja-JP` 显式值；
2. `--lang auto` 或未指定时，读取 `QQ_DUMP_DB_LANG`；
3. Windows 用户界面语言；
4. 回退到 `zh-CN`。

环境变量只接受 `zh-CN`、`en-US`、`ja-JP`；无效值视为未设置并继续回退。无法找到某条翻译时，依次回退到 `zh-CN`，最后显示稳定的消息 ID。

## 6. 兼容性约束

- 保留当前 `--qq`、`--pid`、`--db-dir`、`-o/--output` 参数名。
- 新增 `--output-dir`、`--lang`、`--no-wait`、`--version`。
- 旧参数调用方式仍可运行；默认输出目录和 `-o` 相对路径语义按本规范统一，具体变化见 [兼容性记录](compatibility.md)。
- `--pid` 仍是显式诊断覆盖，不应被解释为“必须与自动识别账号一致”；不一致时需要警告，且不得隐瞒。
